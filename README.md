# 🌿 Smart Classroom Energy Saver System

## 📌 Project Description
Smart Classroom Energy Saver is an intelligent energy management system designed to reduce electricity wastage in classrooms.

The system monitors student presence and daylight conditions to control classroom lights and fans automatically. It also provides a manual override option.

## 🎯 Objectives
- Reduce electricity wastage.
- Automatically control classroom lights and fans.
- Monitor student presence.
- Use natural daylight efficiently.
- Simulate the system using Icarus Verilog.
- Display device status using a modern web dashboard.

## 🛠️ Technologies Used
- Verilog HDL
- Icarus Verilog
- HTML
- CSS
- JavaScript
- GitHub

## ✨ Features
- Student presence detection input.
- Daylight monitoring input.
- Automatic light control.
- Automatic fan control.
- Manual override switch.
- Energy-saving status indicator.
- Live device status dashboard.
- Activity log.
- Responsive mobile-friendly UI.
